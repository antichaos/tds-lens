Find expensive calculations

Drop a .twb or .twbx workbook to find the calculated fields that slow it down, and the sheets and dashboards that use them. Data sources (.tds, .tdsx) work too.

String logic

Text parsed into dates, long IF and CASE chains on strings, regular expressions and other row-by-row string functions.

LOD & table calculations

FIXED, INCLUDE and EXCLUDE expressions, nested LODs, table calculations over table calculations, and table calculations used as filters.

Dependencies & usage

Deep calculation chains, calculations that build on expensive ones, and which sheets, filters and dashboards use each one. Unused calculations are listed too.
