TDS Lens
Runs in your browser

See inside a Tableau data source

Drop a .tds, .tdsx, .twb or .twbx file to see its connections, tables, relationships and performance options, with a diagram drawn the way Tableau draws it.

Structure

Every connection with its tables, joins, unions and custom SQL. Full table names, even when Tableau cut them off at 30 characters.

Relationships

Join fields, cardinality and referential integrity for each relationship. Defaults that were probably never set are flagged.

Debug & document

Checks point out joins and settings worth verifying. Compare two versions or environments, and export everything as Markdown for your documentation.

Private

The file is read by this page, in your browser. Nothing is uploaded, stored or tracked.

How do I get a .tds from Tableau Server or Tableau Cloud?
  1. Open the published data source on Tableau Server or Tableau Cloud.
  2. Choose Download. If the data source has an extract, choose the option without the extract: you only need the definition, and the download stays small.
  3. Drop the downloaded .tds or .tdsx here.

In Tableau Desktop you can also use Data → your data source → Add to Saved Data Sources to save a .tds.

Comparison Tables and relationships are matched by name; schema names are ignored.
